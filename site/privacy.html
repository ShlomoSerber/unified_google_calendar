Privacy policy

Unified Google Calendar is a desktop application that runs only on the user's own computer. There is no server operated by the developer.

Google user data

With the user's consent through Google OAuth, the application reads and writes the user's Google Calendar data (calendars and events) using the Google Calendar API, and reads the account e-mail address to label the account. This data is stored only in a local database on the user's computer and is used only to display and edit the user's calendars.

OAuth tokens are stored encrypted on the user's computer. No data is sent to the developer or to any third party. Data is shared with Google only through the Google Calendar API, on the user's request.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Removing an account inside the application deletes its tokens and local data. Uninstalling the application and running its data removal script deletes everything it stored. Access can be revoked at any time from the user's Google account permissions page.
